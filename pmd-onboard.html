What You Can Change From the Joystick Itself

Before the dealer’s laptop, before the dongle, there is a smaller door: the settings menus already built into the hand control you hold every day. Every major control system has one. None of them were ever walked through for owners. Here they are, system by system, exactly as the manufacturers printed them in their own manuals.

First, the words. The hand control (also called the joystick module, or the remote) is the unit in front of you: joystick, buttons, and screen. The drive screen is its home screen — the one that shows your speed, battery, and current profile. A profile is a saved set of drive behaviour — indoor, outdoor, attendant — built by whoever programmed the chair; you can switch between profiles, but on most systems you cannot edit what is inside one from the hand control. On-board programming, shortened to OBP, is a programming mode built into the hand control itself, as opposed to programming done from a separate tool. A mode is a job the hand control is doing right now — driving, seating, settings — and most hand controls step through modes with a Mode button.

The stance of this page is narrow and deliberate: here is what the maker already left open to you. Every button sequence below is printed in a published owner manual or a published programming guide, and each section names its source. Where a menu exists but a dealer-set switch decides whether you may open it, this page says exactly that — it does not teach you to defeat the switch. And the safety line from the settings page stands in full: some settings can break hardware, including the seating actuator rule — on systems that sense the end of an actuator’s travel by motor current, actuator acceleration and deceleration must stay at 100%. That rule, and what each deep setting means, lives on the settings page; this page does not re-teach deep settings. For the tools and permission tiers behind the locked doors, see the programmers page.

Curtiss-Wright R-net (CJSM2 colour-screen joystick): two doors

R-net chairs with the colour-screen CJSM2 joystick have two menus, and they are not the same door. The Settings Menu is the owner’s menu, printed in the chair’s user manual. OBP is the programming menu documented in Curtiss-Wright’s On-Board Programming manual SK78571 — and whether OBP opens at all was decided when the chair was programmed.

Door one: the Settings Menu (owner level)

Permobil’s CJSM2 user manual (order no. 341124) describes it this way: “The settings menu permits the user to change, for example the clock, the display brightness, and the background color.” On a Permobil-fitted panel:

  1. Press and hold the function button for hazard lights to open the Settings Menu. If your panel’s function buttons are programmed with seat functions instead, first press the Mode button one or more times until the settings icon appears on the screen, then press and hold the function button for hazard lights.
  2. Move the joystick to scroll through the menu. Push the joystick right to enter a submenu.
  3. To leave, select Exit at the bottom of the menu and push the joystick right.

What is inside, per that manual:

  • Time — Set Time sets the clock; Display Time chooses 12-hour, 24-hour, or off.
  • Distance — the odometer (the chair’s mileage counter). Total Distance is stored in the power module and counts everything driven while that module has been fitted; Trip Distance counts since the last reset and can be cleared by you with a right joystick push; Display Distance chooses which of the two the screen shows.
  • Backlight — screen brightness from 0% to 100%; Auto Backlight lets the panel’s light sensor adjust brightness for you (on or off); Backlight Time sets how long the backlight stays on after the last input, from 0 to 240 seconds.
  • Bluetooth and Infrared setup (on panels fitted with them) — pairing devices, and learning or deleting infrared codes for controlling household devices.
  • System — read-only: Diagnostics shows the control system’s diagnostic information, and Timers shows how many hours the chair has been driven. (What the diagnostic codes mean is on the fault codes page.)

Panels differ between chair brands. PGDT’s own R-net CJSM2 user guide opens the same menu by pressing and holding the top left-hand screen button for 1 second. The menu contents are the same family; the button that opens it is the part your chair’s own manual decides.

Door two: OBP (only if it was left enabled)

The OBP manual SK78571 is blunt about the gate: “OBP in the field can be entered via two methods – connection of a hardware dongle or a keycode. The actual method required is set by the factory programming of the control system.” A dongle is a small hardware plug that carries programming permission (the tiers are mapped on the programmers page). The manual also states: “OBP is not possible using an LED Joystick Module.” If your chair has the LED joystick, this door does not exist.

If the dongle method is set, the published sequence is:

  1. Turn off the control system.
  2. Insert the R-net Dongle along the communication cables in the system configuration.
  3. Turn on the control system.
  4. After initialization, press the Mode key until the OBP screen is reached.

If the keycode method is set, the published sequence is:

  1. Hold down the Horn button, then hold down the On/Off button until there is a short bleep. The normal power-up sound occurs before this bleep.
  2. Release the Horn button, but keep holding the On/Off button until there are two further short bleeps.
  3. Release the On/Off button. There is a longer bleep, and OBP mode is entered. (A dongle also opens OBP when the keycode method is set.)

PGDT prints the consequence of that second method in its own manual, verbatim: “If the keycode method is set, then it may be possible for a wheelchair user to gain entry to the OBP function. PGDT accept no liability for losses of any kind if this method of OBP is set. PGDT also accept no liability for losses of any kind if OBP access is gained by unauthorised personnel obtaining a dongle.” Read that carefully: the maker knows the keycode door can be opened by the rider. Whether it is open on your chair was still someone else’s choice.

Inside OBP, navigation is all joystick: forward and reverse deflections move up and down the parameter list; a left deflection on a highlighted parameter title shows its full name, and on the profiled screens a second left deflection goes back a screen. The Speed buttons change a value. The manual’s storage instruction matters: “To ensure all new values are stored correctly, exit OBP mode with a series of left hand joystick deflections.” There is no published “exit without saving” path — leaving any other way is exactly what that sentence warns against.

What OBP contains is the deep parameter tree — speeds, acceleration, deceleration, torque, tremor damping, seating actuator speeds, profile enable, and more. That tree is translated setting by setting on the settings page, and the manual’s own warning, verbatim, is why this page does not walk you through changing them: “Programming should only be conducted by healthcare professionals with in-depth knowledge of PGDT control systems. Incorrect programming could result in an unsafe set-up of a wheelchair for a user. PGDT accept no responsibility for losses of any kind if the programming of the control system is altered from the factory pre-set values.” Knowing the door exists, knowing whether yours is set to dongle or keycode, and knowing the values you were fitted with — that is owner knowledge. The values themselves belong in a conversation with the clinician who fitted you.

Dynamic Controls DX2: there is no menu — and that is the finding

The DX2 hand controls covered by Dynamic’s DX2-REM42x manual (GBK65568) and DX2-ACS2 installation manual (GBK65548) are LED remotes: rows of lights and buttons, no screen, no settings menu, no clock to set. The ACS2 manual defines the system’s position in one sentence, verbatim: “The term ‘programming’ used in this manual refers to adjusting parameters and configuring options to suit an application. ‘Programming’ does not change or alter any software within the controller and is performed using a controlled programming tool available only to authorised personnel.” Every parameter change on DX2 goes through the Wizard PC software or the DX Hand Held Programmer, behind a dealer or OEM dongle — the full tier map is on the programmers page.

What the REM42x buttons themselves do, per the manual, is operation, not programming:

  1. Choose a drive profile: press + or − on the Drive Profile Selection button. The remote supports 5 drive profiles, and the lit Drive Profile LEDs show which one is active. The manual’s own framing: a drive profile is “a specific drive setting (slow or fast, indoors or outdoors) that your therapist or dealer can adjust to suit your personal needs and preference.” You pick among them; you cannot edit inside one.
  2. Run the seating: press + or − on the Actuator Selection button to enter Seating Mode, press +/− or push the joystick left/right to choose among up to 4 seating functions, then push the joystick forward or reverse to move the selected function. Pressing the Drive Profile Selection button returns you to Driving Mode, in the profile you were in before.
  3. Lights (REM420 only): the side light button switches the side/positioning lights; the indicator buttons switch the turn indicators; the hazard button switches the hazard lights.
  4. Lock the chair: if the Lock Enable parameter has been set to Yes by the programmer, hold the On/Off button for more than 4 seconds while the system is on. The system turns off, and after 4 seconds all the Drive Profile LEDs and the Lock LED light. To unlock: press On/Off, then press the Horn button twice within 10 seconds while the Lock LED flashes; miss the 10 seconds and the system turns off again.

Two of those everyday features are themselves gated: the lock only exists if a programmer set Lock Enable to Yes, and sleep behaviour, seating availability, and which profiles exist at all are likewise parameter decisions. On DX2, the honest summary is that the hand control is a set of switches into someone else’s configuration.

Dynamic Controls LiNX (REM400 / REM500 touchscreens): a real settings menu

LiNX chairs with the DLX-REM400 or DLX-REM500 touchscreen remotes have the most complete owner menu of any system here, documented in Invacare’s LiNX REM400/REM500 User Manual (1637423) — a manual whose cover states it “MUST be given to the user of the product.” A function card is one full screen of the remote dedicated to one job — a drive card for driving, a seating card for seat movement — and you move between cards and profiles by swiping.

To open the Menu screen:

  1. Tap and hold the navigation button until the Menu screen appears.
  2. The Menu screen offers Clock, Screen Lock, Glove Mode, Settings, and Odometer. Tap the entry you want.
  3. Tap the close button to leave the Menu screen.

What you can change there, per the manual:

  • Clock: tap the clock to edit the time; arrows adjust hours and minutes independently, and a switch toggles between 12-hour and 24-hour display.
  • Settings → Display: Brightness (a slider); Speedo/Odo Display (show or hide speedometer and odometer information on drive cards); Language (the Menu screen’s interface language); Units (metric or imperial).
  • Settings → Audible Cues: turn the remote’s spoken-style sound cues on or off, adjust their tempo, and set their volume.
  • Settings → Interaction: Tap-Only Mode (tap only, instead of swipe-and-tap); Tap Zone (how large an area around your first touch counts as a tap — the manual recommends a low value for good dexterity, a high value for poor dexterity); Left Hand Mode (mirrors the controls to the left side of the screen).
  • Settings → Connectivity: the Bluetooth connectivity settings for pairing phones and computers.
  • Odometer: view total distance and the trip meter, reset the trip meter to zero, and switch the displayed units between miles and kilometres. The total cannot be reset from this screen — the manual says, verbatim in substance, to contact your provider to reset that value.
  • Glove Mode makes the touchscreen more sensitive so it responds through gloves, and Screen Lock freezes the touchscreen against accidental touches (rain included); turning the remote off and on clears the lock.

LiNX also gives the owner one genuine piece of programming: memory positions. A memory position is a saved seat position — tilt, recline, legrests and all — that the chair returns to on one command. Dynamic’s published LiNX application note, “Operating and Updating Memory Positions”, documents the owner updating those positions from the remote. On a REM400/500:

  1. Reposition the seating to the new target position using the normal seating motions.
  2. Open the settings menu on the remote module.
  3. Select Update Position; a list of pre-defined memory positions is displayed.
  4. Select the memory position you want to overwrite.
  5. An overlay asks you to confirm: select Yes to overwrite it with your current seat position (it is usable immediately), or No to go back to the list without changing anything. That No is this menu’s exit-without-saving.

On a button remote (REM2xx), the same update is a button sequence: activate the memory position you want to update (a momentary activation is enough), reposition the seat, then press and hold the bottom of the drive function selector and the seat function selector rocker switches simultaneously for five seconds. The rocker backlights pulse while you hold; a faster triple pulse confirms success, and an alternating left/right pulse means the update failed.

The gate, stated exactly as Dynamic states it: only memory positions that use angle-sensor feedback and have the parameter “Allow Occupant to Update Position” enabled can be updated by the user, and the application note adds that “some memory positions may be configured by the distributor so that they cannot be updated by the user.” The position names, too, can only be changed from a LiNX Access tool, not from the remote. Everything deeper — drive performance, speeds, seating limits — stays in the LiNX Access tools behind the Access Key, and the user manual carries the matching warning, verbatim: “Wrong settings can make the power wheelchair uncontrollable or unstable. An uncontrolled or unstable power wheelchair can cause an unsafe situation such as a crash.” The service side of this system is Dynamic’s LiNX service manual, preserved in the library.

Quantum Q-Logic 3: the Settings screen

Quantum’s Q-Logic 3 hand control has a Settings screen documented for owners in the Q-Logic 3 Basic Operation Instructions (INFMANU4809, Rev D). Two everyday controls come first, because they are the ones riders actually mean by “settings”: the speed adjustment knob raises and lowers the chair’s speed within the active profile (turn it up to increase, down to decrease; the speed indicator bar follows), and the drive profiles — up to four — are selected by pushing the On/Off and Mode Select Lever up repeatedly to cycle through them, or by pressing the Key 1 select button to jump straight to profile 1. The manual is explicit about the boundary, verbatim in substance: “Drive profiles are set by your Quantum Rehab Provider. Contact your Quantum Rehab Provider to change or add a drive profile.” You choose among profiles; the provider builds them.

To change display, sound, or clock settings, the manual’s path is the same four steps for every subject:

  1. Push the Home Screen button.
  2. Push the joystick left to enter the Settings screen.
  3. Push the joystick up or down through the available setting subjects.
  4. When the desired subject is highlighted, push the joystick right to enter that subject. At any time, a left command returns to the previous menu — that is the way back out.

The subjects the manual walks through:

  • Display → Backgrounds — the screen background.
  • Display → Brightness — the display includes a sensor that adjusts brightness for daytime or nighttime; Brightness Day sets brightness for bright light and Brightness Night for low light. Inside the subject: push the joystick right to switch between day and night, up or down to adjust (each push changes the value by 5%), and left to exit and accept the setting.
  • Display → Set Time — the clock. Push the joystick left or right to highlight the value to change, up or down to adjust it, then highlight Set to keep the new time or Cancel to discard it, and push up to perform the highlighted function. Cancel is this system’s printed exit-without-saving.
  • Sound → System Beeps — settings with a checkbox are switched by a right command: one right command checks (enables) the setting, another unchecks (disables) it.
  • Bluetooth operation — which environmental functions (the chair’s built-in Bluetooth control of paired devices) are available on the Environmental Functions screen.

One Q-Logic 3 setting deserves its own paragraph, because the owner holds the key to the dealer’s door: Prog Access. The manual explains that dealer programming through a paired Windows or iOS device (Prog Access Econ-w / Econ-i) must be enabled on the hand control before it works — verbatim: “Prog Access Econ-w must be enabled to allow the dealer of medical equipment access to the Q-Logic 3 parameters for adjustment. If Prog Access Econ-w is not enabled (even if the dealer of medical equipment has been paired with the Q-Logic 3 previously), the Q-Logic 3 cannot be programmed by the dealer of medical equipment.” The same text is printed for the iOS version. Programming access over Bluetooth is, on this system, opt-in from the rider’s own screen.

The manual also prints, verbatim, why the drive parameters themselves are not on that screen: “The controller program can affect speed acceleration, deceleration, dynamic stability, and braking. If it is programmed incorrectly or outside of the safe limits as determined by your healthcare professional, it can create a dangerous situation. Only your Quantum Rehab Provider or a trained technician should program your controller.” (The chair-level manual for a Q-Logic 3 chair, the Q6 Edge 2.0 owner’s manual, is preserved in the library.)

Invacare MK6i (colour MPJ+ joystick): the 10-second menu

MK6i chairs with the colour MPJ+ joystick (Invacare’s documents also print the name as CMPJ+) hide their owner menu behind a long press, documented in Invacare’s MK6i Electronics Field Reference Guide (part no. 1141471), section 16, “User Settings/Diagnostics”:

  1. Depress (press and hold) the Mode button of the MPJ+ joystick for 10 seconds. The User Settings screen appears, with four choices.
  2. Move the joystick forward or reverse to scroll through the list.
  3. Move the joystick to the right to select a setting.

The four choices, with the guide’s own descriptions:

  • Set Date and Time — “Sets the clock on the color MPJ+ joystick. Adds date and time stamp to error codes.” Move the joystick up or down to change the highlighted value (hour, minute, AM/PM, month, day, year), right or left to select a value or the Set icon, then highlight Set and move the joystick forward to enter the new date and time.
  • Battery Voltage — “Displays current battery voltage. This is a diagnostic test a user can perform prior to a service call.”
  • Fault Codes — displays the chair’s fault codes, each stamped with its date and time, which the guide notes “can be helpful to a provider prior to making a service call.” The fault log screen itself prints its own exit: “MODE to Exit.” (The codes themselves are translated on the fault codes page.)
  • Connected Devices — displays what devices are connected to the system.

That is the whole owner menu: a clock and three read-only windows. Everything else on MK6i lives in the MK6i Easy Remote Programmer, and the guide draws the tier line inside the fault log itself, verbatim: “A professional memory card is required in the MK6i Programmer to view error code and troubleshooting information.” You may read your own fault codes from the joystick, date-stamped, for free. The page that explains what they mean sits behind the professional card — the arrangement the programmers page maps in full.

The summary: five systems, five doors

The pattern across all five is the same one the rest of this section documents: the cosmetic layer — clocks, brightness, backgrounds — was left open almost everywhere, because it costs the maker nothing. The layer that decides how the chair drives was left open almost nowhere, and where a door into it exists at all (R-net’s keycode, LiNX’s memory positions, Q-Logic’s Prog Access switch), whether it works on your chair was decided by whoever programmed it. Your rights in that arrangement are on the repair rights page.
