Start with your own hardware

You don’t need to open anything to start identifying chips. If you have a Linux computer or a Raspberry Pi, the system will tell you what’s inside — no screwdriver required:

$ lspci | grep -i wireless
03:00.0 Network controller: Intel Corporation Wi-Fi 6 AX200
$ lsusb
Bus 001 Device 003: ID 8087:0026 Intel Corp. AX201 Bluetooth
$ cat /proc/cpuinfo | grep "model name" | head -1
model name	: Intel(R) Core(TM) i5-8250U CPU @ 1.60GHz

lspci lists everything on the PCI bus (Wi-Fi cards, graphics). lsusb lists USB devices. /proc/cpuinfo describes the processor. The names you see here are the same ones in the table above.

IoT spotlight: the ESP32

The most common chip in cheap smart-home gear is the ESP32 (or its little brother, the ESP8266), made by Espressif. Unlike phone chips, Espressif publishes full documentation — datasheets, register maps, everything. That’s why a $5 smart plug can run open-source firmware like Tasmota or ESPHome instead of the vendor’s cloud app, and why ESP chips show up all over the table above. See Protocol Reverse Engineering to learn how to take control of one.
