The Attendant Control

Some power chairs carry two driving controls. The main one sits in front of the person in the chair (the occupant). The second one — the attendant control — mounts at the back, on a push handle, so a carer (the attendant) walking behind can drive the chair for them. A chair wired so either control can drive, with a way of passing control between them, is a dual-control chair. This page explains how the two controls share one chair: who is in charge at any moment, how control changes hands, how fast the attendant is allowed to go, and the faults a second live control creates all by itself.

Two people, two joysticks, one chair is a safety question before it is a convenience. Every system below answers it the same basic way — only one control drives at a time — but each maker decides which one, and how the other one takes over, differently. Some of those decisions are switches you can touch. Some are set in programming, where you cannot. This page names which is which.

Provenance: this page is compiled from the manufacturers’ own published documents — Invacare’s LiNX service manual and TDX SP2 owner’s manual, Dynamic Controls’ DX2-REM42x and DX2-REMB-ACS2 technical manuals, PG Drives Technology’s mobility diagnostics guide and R-net programming manual, the R-net operation text carried in Sunrise Medical’s Quickie S-636 / S-646 owner’s manual, and Quantum Rehab’s Q6 Edge 2.0 owner’s manual — and checked against them. Behaviour that could not be confirmed in a manufacturer’s document is not stated as fact. Documentation, not bench measurement: if your chair disagrees with this page, the chair wins — write down what yours actually does.

Before any check on this page that touches a plug or cable: put the chair on level ground, switch it OFF, and disconnect the main battery harness or trip the main circuit breaker. Do not do the check while anyone is seated in the chair. Connector pins can remain live after switch-off. Keep a disconnected cable from touching skin, jewelry, tools, or metal, and cover or restrain it so the pins cannot short. If you cannot disconnect power, inspect visually only and stop.

A second control is a second way for the chair to move. Treat it as live whenever the chair is powered, even when it is not the control in charge: on several systems its power button still works, and on one system below its power button is an emergency stop for the whole chair.

What it is, and where it mounts

An attendant control is a small hand control — a joystick (the stick you push to steer; further means faster), an on/off (power) button, and usually a speed dial or speed buttons that cap the top speed — fitted at the rear of the chair, where a person walking behind can reach it while holding the push handles. It is not a separate machine: it plugs into the same bus (the cable network the chair’s electronic modules talk to each other on) as the occupant’s control, and it talks to the same power module (the box in the base that feeds the motors). Driving from it feels like driving from the front, except that forward is away from you and the chair’s weight is in front of your hands.

Makers sell it under different names. These are the ones this page covers, with the document that describes each:

SystemThe attendant hardwareWhere it mounts

One naming trap: an attendant control is not the same as freewheel mode (the motors disengaged so the chair can be pushed by hand, covered on Start Here). Freewheel is muscle power with the brakes off. The attendant control is full powered driving, from behind.

Who has control — and how it changes hands

This is the heart of dual control. No system on this page mixes the two joysticks together, and none lets both drive at once. Each one picks a single control to be in charge (the makers’ own words: in charge, in control, in focus) and ignores the other one’s joystick. What differs is how the chair decides, and how the two people swap. Per system, as documented:

SystemWho is in chargeHow control changes handsWhat the other control can still do
Invacare LiNX (two remotes, e.g. occupant remote + DLX-REM050)Whichever remote powered the system up. Invacare’s LiNX remote user manual, word for word: “Either remote can power up the system. The remote that powers up has control (remote-in-charge).”There is no mid-drive grab on the standard setup: “To change control, power down the system with either remote, then power up again with the remote that requires control.” One exception: if the system is locked and you unlock it from the DLX-REM050, the REM050 is in charge automatically.Nothing except its power button — and that button still matters: either remote can power the whole system down, and pressing the power button while driving is an emergency stop. You can tell who is in charge from the battery gauge: on the remote that is not in charge, the battery gauge is switched off.
PG Drives R-net (Dual Attendant Module)Whichever side the module’s Control Switch selects. The module’s Control Indicator shows it: “If the red wheelchair light is on, the user’s input device has control. If the green attendant light is on, the Attendant Module has control.” On screen-based R-net systems the module in control displays the In Focus symbol.The Control Switch “transfers drive control of the wheelchair between the User Input Device and the Attendant Module” — a deliberate switch flip at the back of the chair, not a power cycle.The side not in control does not drive. Whether the occupant can take control back from the attendant is not a switch at all: it is a programmed setting (R-net calls the idea allow grab, set under Input Device Type in programming). Traditional attendant setups are configured so the user can never gain control from the attendant; R-net can be programmed to allow it. Which way your chair is set is invisible from the joystick — ask, and see The Keys.
Dynamic DX / DX2 (DX-ACU)The attendant, whenever the User/Attendant switch on the DX-ACU is set to “Attendant”. The occupant remote shows it: the Attendant Profile LED lights, and the chair locks into the Attendant Drive Profile (Drive Profile 6).The attendant releases control back by switching the User/Attendant switch back. Until that happens, the profile cannot be changed: the Attendant Drive Profile “will stay active until the attendant releases control back to the user.”The occupant’s joystick does nothing. The occupant remote’s buttons still work as normal — but pressing its Drive Profile button cannot take the drive profile away from the attendant; at most it returns the remote to Drive Mode.
Quantum Q-Logic 2The input device that powered the chair up. The Q-Logic 2 Basic Operation Instructions state it in one sentence: “When multiple input devices are used, the device that powered up the chair is in control.”Power the chair up from the control that should drive. The newer Q-Logic 3 instructions describe the attendant unit’s layout but defer its use to the provider — “For more information on these applications, contact your Quantum Rehab Provider” — so on a Q-Logic 3 chair, get the handover rule for your chair in writing from the provider.Not stated for the attendant pairing in the public Q-Logic documents this page could check — treat the other joystick as live until you have tested otherwise, with the chair unoccupied.
Invacare MK6iThe attendant, when the attendant control is switched in. The chair announces it rather than hiding it: code W05, “attendant control active” — which is a status, not a fault. It is translated in full on Fault Codes, Translated (part two); this page does not repeat the table.By the attendant control’s own switching, per the chair’s remote manual. The TDX SP2 owner’s manual itself hands the detail off: driving instructions live in the manual for the fitted remote.—

What happens if both joysticks are touched at once? The in-charge joystick drives; the other joystick is ignored — and on PG Drives systems it is worse than ignored. PG’s mobility diagnostics guide lists trip 7107, Primary Joystick Deflected: “The most common cause of this trip is if the Primary Joystick on the Joystick Module is deflected away from center whilst a Dual Attendant Module is in control.” In plain terms: while the attendant is driving, an occupant idly pushing their own stick can trip the chair and stop it. Agree before you move: when the attendant is driving, the occupant’s hands stay off the stick.

And who is allowed to take control is, on LiNX, a programming decision. Invacare’s LiNX service manual describes the “user-in-charge” system: by default there are no restricted users, and “both the attendant and the occupant can request to be user-in-charge at any time by pressing power button.” A provider can restrict that in programming — the parameter offers No Restriction (the default), Occupant Priority (restricts the attendant), Attendant Priority (restricts the occupant) and No Change Allowed (restricts both). A restricted user’s request is simply denied. That setting is changed with the LiNX Access programming tool, not from either control — it is tiered, like the rest of the settings in The Settings.

CAUTION! Risk of injury or damage — “When setting either occupant or attendant as restricted user in user-in-charge-system, consideration needs to be given to whether benefit outweighs risk, since restricted user is unable to take control from user by activating power button in emergency.” — Invacare, LiNX service manual

Speed in attendant mode — the attendant is deliberately slowed down

Every maker treats attendant driving as its own, tamer setup — the attendant is walking, steering a heavy chair from its least stable end, with the occupant’s feet pointing at the obstacles. But there is no universal attendant speed limit in these manuals: no maker here publishes one fixed number that applies to every chair. What each system does instead:

  • LiNX / DLX-REM050: the system powers up in drive function one and stays there — “As an attendant, you cannot change the drive function but can control the maximum speed with the speed dial.” The attendant’s freedom is the dial (ten steps on the main remotes), not the functions; what drive function one means in speed is a programmed value. The larger DLX-ACU200 gives the attendant up to three drive functions and a display showing who is in charge.
  • DX / DX2: attendant mode is a profile. The Attendant Drive Profile (Drive Profile 6) holds its own speeds and accelerations, set in programming, and it cannot be swapped for a faster profile mid-drive — see the handover table above. A slow attendant mode on a DX chair is a programming choice; so is a fast one.
  • R-net Dual Attendant: the attendant module has its own maximum-speed indicator (five steps, step 1 lowest, step 5 highest) and its own speed increase/decrease buttons, separate from the occupant’s speed setting. The attendant picks a step; the actual speed each step allows comes from the attendant profile’s programmed values.
  • Simpler chairs sometimes do hard-cap it. To show the contrast: Drive Medical’s attendant controller kit for its Aerocarbon powerchair states that “when the attendant controller is being used, the maximum forward speed is limited to 3mph.” A fixed cap exists on chairs like that — on the programmable systems above, the cap is whatever the profile says, which is why two chairs of the same model can behave differently.

Plainly: if an attendant mode feels dangerously fast or uselessly slow, that is not a broken part. It is a number in programming — the attendant profile’s maximum speed — and changing it is a programmer job. See The Settings for what those numbers are, and The Keys for who holds the tools.

Faults the attendant control itself causes

A second control is a second joystick to be knocked, a second cable to be crushed, and a second module the system can lose. The fault literature treats it that way. The owner-level ones, per system:

What you seeWhat it meansWhat you check first
MK6i shows W05Attendant control active. Not a fault — the attendant control is switched in and driving.Nothing. Full translation on Fault Codes, Translated (part two).
PG Drives trip 7107Primary (occupant) joystick deflected while the Dual Attendant Module is in control.Hands off the front stick while the attendant drives. Centre the joystick and cycle the power. PG’s diagnostics guide: if it persists, the Joystick Module itself is suspect.
PG Drives trip 3000 / 714D / 7147Dual Attendant joystick deflected at power-up — the attendant was holding or leaning on the stick as the chair was switched on.Let go of the attendant stick, wait for the battery gauge’s start-up blink to finish, and power-cycle. If it persists, PG assumes a defective joystick in the Dual Module.
PG Drives trip 5400 / 7113 / 7124 / 7126 / 7133 (communications trip, VSI)The Dual Module has become disconnected while switched on.The cable between the controller and the Dual Module: properly connected, and in good condition along its whole run. The chair is not dead: switch off, leave the Dual Module disconnected, switch on again, and the chair drives from the user control.
PG Drives trip 7140 / 7142Dual communications trip between Joystick Module, Dual Attendant Module and Power Module.Check each cable for continuity (a meter check that the wire is unbroken end to end). If the cables are sound, PG’s verdict is that the Dual Attendant Module itself must be assumed defective.
PG Drives trip 7164Dual Attendant joystick orientation error — the data that tells the module which way its stick points has been corrupted, possibly by an incorrect or incomplete orientation sequence.The fix is re-performing the orientation sequence in the diagnostics guide — a service procedure, not a setting. PG Drives trip 7B00The Dual Module was connected while the system was already switched on.Switch off, connect the module, switch on again. Hot-plugging the attendant control is itself the fault.

A fault on either remote is also shown on both remotes.Cycle the power to clear it. Reconnect and check the missing remote’s cable and plug. Note the trap in Invacare’s manual: if the power button of the remote-in-charge is faulty, the system does not operate at all — the healthy remote cannot simply take over.
DX shows 2 flashesDX accessory fault: an accessory device on the DX Bus — the class the attendant module belongs to — is faulting or sending a slow/stop signal.Unplug accessories one at a time to find the culprit, attendant module included. Full DX table on Fault Codes, Translated (part two).

The weak point is the cable at the push handle. The attendant control lives where hands grip, bags hang, door frames clip and the chair gets lifted and folded. Invacare’s LiNX service manual mounts it “using a bracket on the push handle or the push bar” and routes its cable down the back of the chair with everything else — the run most exposed to flexing and knocks. Invacare’s remote manual is explicit about what that does to a bus cable: “Regular bending can damage the bus cable.” When an attendant control fails intermittently, works at some backrest angles and not others, or faults when the push handle is touched, suspect that cable run and its plugs before you suspect the module — the general method is Procedure 4 in The Cheap Fixes, and reading the chair’s behaviour first is Reading the Chair.

The manufacturers’ own warnings — word for word

Attendant driving is where the manuals stop being generic. These are carried verbatim, with the maker named; emphasis is theirs.

“Test the behavior of the attendant control unit without an occupant to avoid injury. When handing over to other attendants, ensure they are sufficiently instructed.” — Invacare, LiNX remote user manual, on the DLX-REM050 attendant control unit

WARNING! “Make sure you heed all warnings and follow all instructions in each section of this manual. (Be aware that warnings that apply to the rider also apply to you).” — Sunrise Medical, Quickie S-636 / S-646 owner’s manual, “Notice to Attendants”

“In the event of the wheelchair moving in an unexpected way RELEASE THE JOYSTICK. This action will stop the wheelchair under any circumstances.” — PG Drives Technology / Sunrise Medical, R-net Control System user manual, “Precautions for Use”

CAUTION! Risk of tipping over — “Never approach obstacles at an angle but at 90 degrees as shown below.” Invacare’s TDX SP2 owner’s manual states immediately before this section that “the following instructions how to take obstacles also apply for attendants if the power wheelchair is fitted with an attendant control.”

CAUTION! Risk of tipping over — “Only ever drive downhill at a maximum of 2/3 of the top speed. Avoid sudden changes of direction or abrupt braking when driving on slopes.” — Invacare, TDX SP2 owner’s manual

WARNING! “Freewheel mode should only be used on level ground and when an attendant is present to control the wheelchair. If you use freewheel mode on an incline or without an attendant, you can get injured or cause property damage.” — Permobil, M3 Corpus owner’s manual (the same warning appears in the F5 Corpus VS owner’s manual)

CAUTION! Risk of the power wheelchair running away — “The motors may only be disengaged by an attendant, not by the user. This ensures that the motors are only disengaged if an attendant is available to secure the power wheelchair and prevent unintended rolling.” — Invacare, TDX SP2 owner’s manual

Safe setup checklist for families

Nothing here needs a tool. It is the agreement two people make before a heavy chair moves with a person in it:

  1. Agree who is driving, out loud, before the chair moves. Then confirm it on the chair: green attendant light or In Focus symbol (R-net), the Attendant Profile LED (DX), a live battery gauge on your remote and a dark one on the other (LiNX), or W05 on the screen (MK6i). If the indication and the agreement disagree, stop.
  2. Practise with the chair empty first. That is Invacare’s own instruction, quoted above: test the attendant control’s behaviour with no occupant in the seat, in an open space, until stopping is boring.
  3. Start at the lowest speed setting — dial down, step 1, profile as delivered — and only raise it when the attendant can stop the chair dead, on purpose, without a lurch. Walking pace is the ceiling that matters, whatever the profile allows.
  4. Occupant’s hands off. While the attendant drives, the occupant does not touch their joystick: on PG Drives systems that alone can trip the chair (7107), and on every system it breaks the one-driver agreement.
  5. Both people know the stop. Releasing the joystick stops the chair. Pressing the power button while driving is an emergency stop on LiNX, and either LiNX remote’s power button powers the system down — including the occupant’s. Agree who calls it.
  6. Kerbs head-on, never at an angle (Invacare’s warning, above), front wheels square to the obstacle, slow and at a steady speed. If you are pushing by hand in freewheel instead, Sunrise’s attendant method is to stay at the rear, and to descend a kerb backwards, lowering the rear wheels first.
  7. Slopes slower than feels necessary: downhill at no more than two-thirds of top speed (Invacare, above), straight up or straight down, never turning across the slope, and never in freewheel without an attendant holding the chair.
  8. Check the attendant cable weekly — the R-net manual’s weekly checks (cables for damage, connectors secure and properly mated, joystick gaiter intact) apply double at the push handle, where the attendant lead flexes and gets knocked. A chafed attendant cable is next month’s communications trip.
  9. Hand over properly. A new attendant gets the same empty-chair practice and is told who is in charge, how to hand control back, and how to stop — before they drive a person anywhere. If your chair’s handover works differently from this page, write down how yours works and keep it with the chair.

If the chair’s problem is bigger than its controls — a dealer refusing a repair, a part held hostage — see Repair Rights and The Repairs. If the chair has stopped entirely, start at Start Here.
