Fault Codes, Translated: The Other Systems

Part one translated the codes for VR2, VSI, R-net and LiNX. Three more systems cover most of the chairs that were left: Dynamic Controls Shark, Dynamic Controls DX and DX2, and Invacare’s MK6i. Same deal as part one: what the code means, what you check first, in what order.

Find your system, read the code the way the chair shows it, and write it down before you call anyone: a code you can name is a repair you can argue about.

Provenance: these tables are compiled from the manufacturers’ own published documents — Dynamic Controls’ Diagnostic Flash Code Listings and SHARK manuals, and Invacare’s MK6i Field Reference Guide (part no. 1141471) and TDX service manuals — and checked against them. Codes that could not be confirmed in the manufacturers’ documents are not listed. Documentation, not bench measurement: if your chair disagrees with this page, the chair wins — write down what yours actually does.

Before any check in these tables that touches a plug, cable, motor, brake, actuator, or battery terminal: put the chair on level ground, switch it OFF, and disconnect the main battery harness or trip the main circuit breaker. Do not do the check while seated in the chair. Connector pins can remain live after switch-off. Keep a disconnected cable from touching skin, jewelry, tools, or metal, and cover or restrain it so the pins cannot short. At a battery terminal, work on one terminal at a time with an insulated tool. If you cannot disconnect power, inspect visually only and stop.

The manufacturers’ own warning, carried word for word from a Shark owner’s manual: “Note: SHARK is not user serviceable. Specialized tools are necessary for the repair of any SHARK component.” True — for repairs inside the components. Reading a flash code needs no tools at all: the chair displays it for free, on purpose, where you can see it. That is the part this page uses.

Dynamic Controls Shark — count the flashes on the gauge

Shark is the system on a large share of scooters and mid-range power chairs. Its joystick unit has a row of lights (the information gauge). The lights speak before any code appears:

  • Left red light flashing: battery charge is low. Charge as soon as you can.
  • All lights flashing slowly: the joystick was out of neutral at power-up (Dynamic’s name for it: OONAPU — something was pushing the stick when you switched on). Let go of the stick; it clears itself. This is not a fault.
  • All lights flashing quickly: the chair has detected a fault. Count the flashes in the repeating pattern — that count is the code.
  • Two amber lights flashing: a communication fault between the joystick unit and the power module. Check the power module for a fault, check the cable between them for damage, and make sure the battery is charged.
  • Lights chasing right-to-left just after switch-on: the chair is coming out of lock mode. Press the horn twice within 10 seconds of switching on to unlock it.
  • Right green light flashing: the chair is in speed-limit mode (often because the seat is raised) — a mode, not a fault.
FlashesWhat it meansWhat you check first
1 flashUser faultDynamic lists this as a possible stall timeout or user error: the chair was driven against something it could not move, or held at stall. Reverse away, let the joystick return to center, and try again.
2 flashesBattery faultCheck the batteries and their cabling: main plugs, terminal bolts, breaker. Load-test the pair if it keeps happening (see Cheap Fixes, Procedure 3). Dynamic’s note is blunt: the batteries may require replacing.
3 flashesMotor 1 fault (M1 is normally the left motor)Check the motor, its heavy plug at the power module, and the cable run for pinches or cuts.
4 flashesMotor 2 fault (M2 is normally the right motor)Same checks as 3 flashes, on the Motor 2 side.
5 flashesLeft park brake faultThe electric brake in the left motor. First: the left freewheel lever — flip it firmly to DRIVE. Then the small 2-pin brake plug behind the motor (Procedure 1).
6 flashesRight park brake faultSame checks as 5 flashes, on the right: freewheel lever to DRIVE, then the brake plug.
7 flashesShark control unit (joystick unit) faultThe fault is inside the joystick unit itself. Check its cable and plug first — a bad connection can condemn a good unit. If the code stays, the unit is the fault.
8 flashesShark power module faultCheck every connection and wire at the power module in the base. If all are sound and the code stays, the fault is inside the power module.
9 flashesShark communications faultThe joystick unit and power module have lost contact. Unplug the bus cable between them, check the pins, reconnect firmly (Procedure 4).
10 flashesUnknown faultThe system knows something is wrong but cannot name it. Check all connections and wiring; photograph the gauge and note the code before calling — Dynamic’s own action for this code is “consult a service agent,” and the code is your evidence.
11 flashesIncompatible control unitA part that does not belong to this system has been fitted: Dynamic states the branding of the power module must match the control unit. This code appears after a wrong-part swap — ask what was changed.

Dynamic Controls DX & DX2 — the status light codes

DX is Dynamic’s older modular system: separate power, seating and lighting modules on one bus (the DX Bus — the cable network the modules talk on). Faults show as flash codes on the remote’s status light: count the flashes, pause, repeat. Dynamic names the drive channels M1 and M2 — M1 is normally the left motor, M2 normally the right; identify a motor by its plug, not only by side.

FlashesWhat it meansWhat you check first
1 flashDX module faultIf the chair has just been reprogrammed this may not be a real fault: switch off and on to clear it. Otherwise check the DX Bus connectors and cables, look at the status lights on the other modules, and confirm every module that should be present is connected.
2 flashesDX accessory faultAn accessory device (anything connected to the system other than the power module) is sending a slow/stop signal or has a fault. Unplug accessories one at a time to find it.
3 flashesMotor 1 fault (normally left)Check the motor, its connections and cabling.
4 flashesMotor 2 fault (normally right)Check the motor, its connections and cabling.
5 flashesLeft park brake faultFreewheel lever firmly to DRIVE; then the brake’s connections and cabling (Procedure 1).
6 flashesRight park brake faultSame checks as 5 flashes, on the right brake.
7 flashesLow battery faultDynamic’s own check: battery voltage must be above 17V for the pair. Check battery connections and terminals, then the batteries’ condition (Procedure 3).
8 flashesOver-voltage faultDynamic’s check: battery voltage must be below 32V. Check the battery wiring and that every terminal is secure — and suspect the charger if this follows charging.
9 flashesCAN L faultA fault on one wire of the DX Bus. Check the condition of the bus cables and connectors along their whole run.
10 flashesCAN H faultThe other bus wire. Same cable checks as 9 flashes; Dynamic also notes to check the hazard lights were not switched on at power-up.
11 flashesStall timeout faultThe motors were held stalled too long (a wheel against a wall or a high threshold). Make sure both motors can turn freely, then switch off and on.
12 flashesModule mismatchA module or its software does not belong with the rest of the system — Dynamic’s action is reprogramming, which is a programmer job (see The Keys). This code after a part swap means the swap was never configured. Name the code when you call.

Invacare MK6i — read the E-code on the screen

MK6i is Invacare’s own electronics, fitted to the TDX line and other Invacare chairs. On chairs with the colour MPJ+ joystick, faults appear on the screen as E-codes, and the chair keeps a fault log — a dated, time-stamped history of every code, which is evidence: do not let anyone clear it before it has been read. On the simpler SPJ+ joystick (no screen), codes are shown on the joystick’s information gauge and read in full with the Remote Programmer.

CodeWhat it meansWhat you check first
E01 / E02 / E03 / E04Joystick or input value out of range (one code per direction: forward, reverse, left, right)Something is holding the stick or input off centre, or it was deflected at switch-on. Clear the stick, let it centre, power-cycle. If one direction’s code returns, the input itself is suspect.
E09 / E10Bad motor connectionInvacare’s service manual, word for word: “Check all connections. Ohm out each brake coil.” Start with the motor plugs at the controller; a brake-coil check is a multimeter job (a meter measures the coil’s resistance — an open coil reads as no connection at all).
E18Joystick or input device failedCheck the input’s cable and plug at both ends. If connections are sound, the input device itself has failed its self-check.
E19Joystick calibration values out of rangeThe chair no longer trusts where the stick’s centre is. Recalibration is done through the programmer — name the code and ask for a calibration before anyone quotes a new joystick.
E32Joystick or input device disconnectedThe controller cannot see its input at all. Follow the cable from the joystick down: unplugged, pinched, or cut are the usual causes.
E41Communications fault latched at switch-offThe controller recorded a fault during the previous shut-down. Power the chair off and back on; if E41 returns, write it down with the date — it points at an intermittent cable or module.
E200“SPM NOT CONNECTED” — the display/joystick module is not communicating with the control moduleCheck the connections between the joystick or display and the controller. Power off and back on. Invacare’s manual: if it persists, the controller is the suspect — after the cable, not before.
W05Attendant control activeNot a fault. The attendant control (the second control some chairs carry for a carer) is switched in and is driving. The chair is doing what it was told.

One lock remains on this system: Invacare’s guide states that reading the fault log’s causes and troubleshooting steps requires a professional memory card in the programmer. The codes above are what the chair shows you for free. The explanations behind them are tiered — which is why this page exists, and why The Keys names the card system in full.

Before you call anyone

Read the code. Count it twice. Write it down with the date — on MK6i, photograph the screen, because the fault log behind it is evidence. Try the owner check in the table: on these three systems, as on the first three, the codes that strand people most are brake levers, a dying battery, and a loose bus plug. If the fault is inside a module, you now know which module — and you can say so.
