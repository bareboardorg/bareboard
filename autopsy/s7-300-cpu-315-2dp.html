Autopsy Report — Siemens SIMATIC S7-300 · CPU 315-2 DP (6ES7315-2AG10-0AB0)

Status: documentation phase — bench work pending. This report contains verified public documentation only. No bench findings are claimed; every pending item is dated and marked. That is the standard.

Findings

A. Verified from public documentation (numbered, cited)

  1. Compute & memory. 128 KB integrated work memory; load memory on a SIMATIC Micro Memory Card (MMC) up to 8 MB; the CPU requires an MMC to operate [1][2].
  2. Interfaces. MPI for programming/HMI/global data (up to 12 Mbit/s) and PROFIBUS DP as master or slave (up to 12 Mbit/s, up to 124 DP slaves) [2].
  3. Power. Integrated 24 V DC supply input [1]; in a full rack, PS307/PS305 modules supply 24 V DC from 120/230 V AC mains (PS305: 24–110 V DC input), in 2 A, 5 A, and 10 A variants [1][8].
  4. Scale. Up to 16,384 digital I/O, 1,024 analog I/O, 4 racks [4].
  5. Architecture. Modular rack system on a mounting rail: PS power supply, CPU, SM signal modules (321 digital-in, 322 digital-out, 331 analog-in, 332 analog-out), IM interface modules, CP communication modules, joined by the P-bus backplane [4][5].
  6. Identification. "CPU 3xx" label on the front panel; the 6ES7 prefix marks the STEP 7 PLC family; middle digits encode module function; the suffix encodes communications (PN, DP, PN/DP, C = compact) [4][5]. S5 units are labeled "CPU 1xx/2xx" — a different rack architecture [4].
  7. Service reality. Siemens does not sell the CPU main board separately — board-level repair means third-party rework or whole-module replacement. No-power faults trace to the PSU, the memory card, or board damage (burn marks, bulging capacitors) [9].
  8. Documentation. The official Installation Operating Instructions (A5E00105492-08, 06/2008) are public from Siemens, and preservation copies exist on archive.org [6][10].

B. Bench findings — PENDING (dated 2026-10-08)

No bench work has been performed or claimed. Planned steps, each to be evidenced when done:

  1. Photograph all labels, connectors, and switch positions before opening anything.
  2. Open the CPU module; record every chip marking. Siemens module markings decode with the public part-number system [5]; third-party chips go to the datasheet hunt.
  3. If the rack PSU is present: open the PS307 after discharging the mains capacitors; photograph the board; check electrolytics for bulging [9].
  4. Inspect the MMC slot and any card present (read-only; image, never write).
  5. Record the MPI/DP connector pinout against the public manual [6].
  6. Check the battery compartment; record the cell type from its label (not yet verified).
  7. Bench power-on: current-limited 24 V DC, no fieldbus attached; record LED behavior (SF/BF/DC5V) against the public diagnostics documentation [9].

Chip inventory

Pending bench work (step 2 above). Public context that will help: Siemens' own part-number system decodes module markings [5], and the rack's PS/SM/IM/CP modules each carry decodable 6ES7 numbers [4].

Safety notes

  • Mains hazard: PS307/PS305 are mains-connected (120/230 V AC, Class I, grounded). Discharge capacitors before opening; treat the primary side as live until proven otherwise [7][8].
  • Battery: a backup cell compartment is expected on the CPU module — type to be verified from the label on the bench (dated 2026-10-08).
  • Fieldbus: never connect a bench PLC to a live PROFIBUS DP network or in-service I/O. Retired unit, bench only.
