Glossary

Every technical term we use, in plain language. If a term is missing, that's a bug — tell us on Contribute.

TermPlain meaning
DatasheetThe manufacturer's public document describing a chip: what it does, its pins, its limits. The most valuable public document in repair.
SchematicA map of how components are wired together on a board. Tells you what connects to what.
PCBPrinted circuit board — the physical board components are soldered onto.
RegisterA chip's internal control slot. Writing a value to a register changes what the chip does.
MMIOMemory-mapped I/O — a way chips expose their registers as if they were memory addresses the CPU can read and write.
FirmwareThe software running inside a chip or device, below the operating system.
JTAGA hardware debug interface on chips, used by factories and repair benches. Often locked after manufacturing.
e-fuse / OTPOne-time-programmable hardware fuses inside a chip. Once "burned," they can't be undone — they set permanent security states.
PMICPower management IC — the chip that decides which parts of a board get which voltage, and when.
SoCSystem on a chip — CPU, GPU, memory controller, and more on one piece of silicon.
SEP / Secure EnclaveApple's isolated security coprocessor. Holds keys and biometric data so the main processor can't read them.
PLCProgrammable logic controller — the industrial computer that runs pumps, motors, and whole plants.
FTLFlash translation layer — the SSD controller's system for pretending worn-out flash blocks are fine.
VSCVendor-specific command — a hidden command a manufacturer adds to a standard interface, outside the public specification.
NDANon-disclosure agreement — a contract that keeps a document secret. Sealed documents are not public documents.
I²C / SPI / UARTThree common low-speed ways chips talk to each other over short wires.
DFUDevice firmware update — a mode that lets you reflash a chip. Its presence is a good openness sign.
Autopsy reportBareBoard's core document: what's actually inside a device, verified and dated.
